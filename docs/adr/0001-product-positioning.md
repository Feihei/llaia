# ADR-0001: LAIA 产品定位

- 状态：Accepted
- 日期：2026-07-21
- 决策者：Owner（单用户）

## 背景

README 列出的功能横跨编码助手、跨设备私人助理、知识中枢三类产品形态。
若不收敛核心场景，MVP 范围会失控，架构决策（频道路由、Agent 人格、工具优先级）也会失去锚点。

## 决策

LAIA 定位为 **单用户私人助理**，次要承担电脑操作与文件读写任务。
单用户身份明确：不支持多用户体系，所有频道身份（QQ openid / 邮箱 / Web 账号）都绑定到唯一的 owner。

## 影响

- 频道优先级：CLI 先行，QQ v1.5 加入，Web 面板 v2。
- Agent 人格偏助理属性，不是纯 coding bot。
- 工具优先级：文件读写、终端、网页、搜索同为基本工具。
- 权限模型简化：不区分多租户，只有 owner 一人。
- 安全边界：本地单用户场景下，沙箱隔离非必需。
