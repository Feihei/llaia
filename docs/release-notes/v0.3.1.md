# LLAIA v0.3.1

Stability fixes and quick wins for the P6 milestone.

**Bug fixes**
- Provider: fixed `context_size` auto-detection (strips trailing `/v1` before probing `/props`), and preserved the fallback chain when switching providers via `/provider`.
- Agent: `/stats` token estimate now counts runtime context and per-message overhead — matches what is actually sent.
- WebUI: model-probe button no longer breaks after the first click; added an ENV read-only panel and a Doctor page (provider connectivity, model chain, context-size, `.env` perms, sessions.db, cron/MCP, skills).
- QQ: fixed rich-media image upload by migrating to the Tencent v2 JSON API; tool notifications collapsed to one message per turn.

**Features**
- Auto Tail Reminder: derives a ≤120-token behavioral checklist when SOUL/USER drift, injected right before generation to counter long-session style drift.
- New slash commands: `/skill list [--all]`, `/reasoning on|off`, grouped tool counts in `/stats`.
