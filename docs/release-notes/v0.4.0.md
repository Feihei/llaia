# LLAIA v0.4.0

Milestone release closing out **P6**. The workspace version was sitting at the pending `0.3.2`; since this batch is feature-heavy it ships as a minor bump, folding all unreleased `0.3.2` work into `0.4.0`.

## Highlights

- **Task-line sessions** ([ADR-0031](../../adr/0031-task-session-model.md)) — besides the general line, open explicit task lines bound to a directory (`kind='task'` + `bound_path`): `/task <name>` to enter/exit, `/tasks` to list, `/task close` to archive. Switching lines re-injects the target line's SQLite tail (6000-char budget, user/assistant text only to avoid orphan tool messages). `/move` now hints at opening a task line. Time/round-based auto-splitting was evaluated and rejected (it floods the list on small-context models).
- **`/btw` side questions** — answer a side question from current context without polluting the main history: single-shot, tool-less, via `compact_provider` with fallback to the main model; results land in a separate `side_messages` table (not in messages/FTS). Renders as a distinct message block in the WebUI.
- **`/steer` mid-turn interjection** — feed hints into a running turn without interrupting it; buffered on a lock-independent channel and injected as a `[steer] User added:` message at the top of non-final tool-loop iterations.
- **Generation Guard** ([plans/2026-09-03-generation-guard.md](../plans/2026-09-03-generation-guard.md)) — framework defense against small-model output degeneration (repetition loops, runaway/empty thinking). A character-level sliding-window n-gram detector + thinking cap + empty-output check aborts the stream, discards the bad product (never persisted), then force-retries with thinking disabled. Seven `guard_*` runtime keys plus an `output_guard` master switch, hot-reloadable.
- **First-run bootstrap** ([plans/2026-09-04-first-run-bootstrap.md](../plans/2026-09-04-first-run-bootstrap.md)) — when SOUL/USER are still the `init` placeholders, a `[bootstrap]` instruction is injected (never into the cached system prefix, so KV stays stable) telling the agent to do its task first and append ≤5 profile questions; answers are written back via `file_edit`. Zero new state, self-terminating.
- **Trusted-directory model for `/move`** — approved dirs join the workspace as a session-scoped trusted set; the approval layer and the execution layer now share one scope check, eliminating the "approved but fails as outside-workspace" split.
- **WebUI**: token-usage Stats dashboard (`turn_usage` table + `GET /api/stats/tokens`, hand-drawn SVG/CSS charts, zero chart dependency), About-page update-check, and sticky sidebars with scroll-to-top/bottom buttons.
- **Send-media scope fix**: `send_image`/`send_file` now follow `/move` (share the same scope Arcs as the file tools); the WebUI `/file` endpoint got the same treatment.

## Provider / model handling

- **Reasoning leakage fixed**: Ollama / llama.cpp presets now default `reasoning_to_content = false` ([ADR-0026](../../adr/0026-provider-compat.md)) — these endpoints return the real answer in `content` with thinking as an extra stream, so folding it in only mixed reasoning into visible text and memory. The `model_folds_reasoning` per-model rule was removed (it only forced that folding in LLAIA). Endpoints that genuinely need it can still opt in via `[provider.<id>.compat] reasoning_to_content = true`.
- **`/provider` persistence**: switching models now writes `[agent.<alias>].model` in place (`toml_edit`, comments preserved); `--temp` keeps the old in-memory-only behavior. `context_size` is now lazily resolved + cached per active provider, so the compaction threshold follows the current model.
- **`native_tool_calling` folded into `Compat` auto-detection** (`Option<bool>`, `None=auto`); no more manual per-model setting.
- Per-model availability probe button in the provider config page.

## Bug fixes / stability

- **QQ**: large-file uploads (was 500/850012) now use the official chunked upload path (`upload_prepare` → presigned PUT parts → `upload_part_finish` → merge), images keep base64 with auto-fallback, and bodies always carry `file_name`. WS reconnect on token expiry fixed.
- **Provider**: SSE now normalizes `\r\n\r\n` (CRLF) event delimiters — previously whole replies were silently dropped behind some proxies; empty `tool_call` name/id deltas are ignored and messages sanitized; IP-style llama.cpp/Ollama endpoints hit the compat presets (usage reporting works).
- **Agent**: `cheap_normalize` no longer drops empty-text `assistant(tool_calls)` messages (which produced orphan tool messages → strict endpoints 400); `StreamEvent::Error` keeps already-generated partial output.
- **Terminal / path-guard**: literal `\n` and bare `/` are no longer misparsed as out-of-workspace paths; `workspace/tmp` is swept of 3-day-old files on startup.
- **Web**: newly added provider API keys take effect immediately (no more bogus `environment variable referenced but not set`); context fit hardened for small-window providers.
