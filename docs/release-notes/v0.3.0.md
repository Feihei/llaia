# LLAIA v0.3.0

Milestone release delivering **P5** and a batch of stability fixes. Workspace version jumps straight from 0.2.2 to 0.3.0 (P5 is a milestone, so we skip a patch).

## Highlights (P5)

- **Provider Compat layer** ([ADR-0026](../../adr/0026-provider-compat.md)) — normalizes divergent OpenAI-compatible endpoints (Ollama / Llama.cpp / LM Studio): reasoning folding, `max_tokens` field switching, streaming usage, finish-reason inference, auto-detected per host with manual override.
- **System-prompt MEMORY budget** ([ADR-0025](../../adr/0025-system-prompt-memory-budget.md)) — MEMORY.md is fully loaded but capped by a configurable token budget; overflow is summarized (or hard-truncated) while SOUL/USER always stay verbatim. New `/memory-compact` command.
- **Unified `search` tool** ([ADR-0023](../../adr/0023-unified-search.md)) — replaces the old `tavily_search` with a single `search` tool routing to Tavily / Baidu / Brave.
- **`todo` tool** ([ADR-0024](../../adr/0024-planning-todo.md)) — built-in lightweight task list so the agent plans non-trivial work step by step; reflected in the WebUI.
- **`ask_user` blocking clarification** ([ADR-0022](../../adr/0022-ask-user-suspend-resume.md)) — agent can pause mid-turn, ask a question, and resume on your reply. New `/answer` and `/cancel` commands.
- **Skill authoring** ([ADR-0027](../../adr/0027-skill-authoring.md)) — `skill_create` / `skill_edit` tools let the agent write and maintain its own skills; ships with a meta-skill to guide when to do so.
- **Long-term goals** ([ADR-0021](../../adr/0021-goal-system.md)) — `/goal` persists a cross-session objective in `goal.md` and re-injects it every turn.
- **Remaining items**: environment probing (`/env`), WebUI session history browser, model probing in the config page, sensitive-field `.env` automation, and a TTS tool (`tts`).

## Bug fixes / stability

- **terminal (Windows)** — now runs commands through Git Bash over stdin, fixing broken double quotes, unexpanded `;`/`$VAR`, and Chinese GBK mojibake. Falls back to `cmd` when no Git Bash is found.
- **Agent** — base64 images returned by tools (e.g. blender-mcp screenshots) are stripped to an `[image]` placeholder, re-encoded, written to disk, and surfaced as media; oversized non-image results are truncated. In-turn context compression prevents a single tool chain from blowing the context.
- **cron** — session reuse / global lock / timezone drift fixes, plus timeout and isolated-turn fixes; the `morning_news` template now constrains sources and hints at tuning `web_fetch` `max_chars`.
- **WebUI** — tool-result folding, MCP/channel cards, comment-preserving config save, live model dropdowns.
- **skill / CI** — recursive subdirectory scanning; lingering fmt/clippy cleanup.

## ⚠️ Breaking changes

- Cron tasks referencing the old tool name `tavily_search` must be updated to `search`.
- Deprecated config fields (e.g. `agent.workspace`) removed from the schema.
