# LLAIA v0.6.0

Feature release. Headlines: task lines become parallel Agent instances
(ADR-0032), the config schema is reorganized into a model catalog (P8,
with automatic migration), and restart is now an in-place reload.

## Breaking / migration

- **Config schema**: `[provider]` narrows to a connection registry
  (endpoints + credentials); models move to a top-level `[model.<id>]`
  catalog with `kind` (chat / tts / image / embedding). Old-style
  `[provider.<pid>.<alias>]` model subtables, `[tools.tavily|baidu|brave]`
  credential sections, inline tts/image_gen endpoints and
  `use_tavily_extract` are migrated automatically at load time —
  in-memory, idempotent, disk untouched; model ids keep the `pid.alias`
  form so existing agent references resolve unchanged. Explicit unknown
  provider `type` now errors at startup instead of silently becoming an
  LLM endpoint.

## Features

- **Instance architecture** (ADR-0032) — task lines are now parallel
  Agent instances; serve is just a host and `main` is an instance too.
  `/session <name>` rebinds the channel after an idle check (three-state
  busy reason). Task instances get private MEMORY files
  (`workspace/instances/<name>/MEMORY.md`) and a read-only guard over
  the home workspace. WebUI gains an instance rail and parallel
  per-instance panels on a single connection; approvals and questions
  aggregate across instances.
- **In-place reload** — `POST /api/restart` no longer spawns a
  replacement process. The whole subsystem (agents, tools, MCP,
  channels, cron, web listener) is rebuilt in-process from config.toml
  with the same PID; a broken config errors visibly instead of running
  with stale settings.
- **image_gen / image_edit tools** — OpenAI-compatible image endpoints
  (sd-server, agnes, OpenAI, ...). Credentials and model come from a
  kind=image catalog entry; artifacts land in `workspace/images/` and
  are delivered via `send_image`.
- **WebUI approval cards** — tool approvals render as inline cards with
  Approve / Deny; buttons reuse the existing `/ok` `/deny` resume path
  so turn output stays on the originating connection. `GET
  /api/approvals` restores cards after a page reload.
- **WebUI question cards** — `ask_user` questions render as inline cards
  with one-click choices plus a custom-answer input; answered cards
  collapse to a verdict line. Replaces the read-only QUESTIONS panel.
- **Models tab** — card grid with provider/kind/multimodal filters,
  two-stage probe/manual add flow, per-card enabled toggle, thinking
  panels; masonry layout with JS-assigned columns so expanding a card no
  longer reflows the whole grid. Provider cards join the same layout
  with a type dropdown.
- **MCP** — stdio servers that reject `initialize` with `-32601`
  (handshake removed in the 2026-07-28 spec, e.g. Python mcp SDK 2.0)
  downgrade to stateless mode with a single warning instead of failing.
- **CLI** — `/models` (catalog listing) and `/providers` (registry by
  family); `/provider` kept as an alias.

## Bug fixes

- Generation Guard no longer punishes a compliant empty reply after
  `/deny` (the deny feedback now asks for a one-line acknowledgment, and
  retry notices carry the actual degeneration reason).
- QQ approval buttons opened to all users — the client-side per-user
  restriction blocked taps on iOS without ever sending the callback;
  identity is enforced server-side.
- Cron agent-mode pushes only the final assistant message; pre-tool
  narration no longer leaks into pushed digests.
- CodeMirror corruption fixed (reactive-proxy references broke
  internal identity checks: Enter duplicated lines, deletes misapplied);
  editors reattach after `x-if` teardown instead of silently dropping
  edits; raw editors warn before discarding unsaved changes; the
  thinking panel collapse no longer depends on config presence.

## Dependencies

- axum 0.7 → 0.8, rusqlite 0.31 → 0.40 (bundled SQLite 3.45 → 3.50),
  tokio-tungstenite 0.23 → 0.29, plus assorted minor bumps.
