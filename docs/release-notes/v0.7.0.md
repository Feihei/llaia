# LLAIA v0.7.0

Security and resilience release. Headlines: the ADR-0033 security model
lands in full (workspace snapshots, egress gates, T2 deployment
hardening, memory hygiene), the WebUI gains a message queue and
read-only built-in tools (`file_list` / `file_grep` / `sqlite_query`),
and approval cards become actually usable on long-lived pages.

## Security (ADR-0033, all phases)

- **Workspace snapshots** — A0/A2 assets (SOUL/USER/MEMORY incl.
  instance-private, sessions.db, uploads/) are backed up before every
  write plus a periodic sweep (sessions.db via `VACUUM INTO`).
  Content-addressed storage under `<config_dir>/snapshots/`, 14-day
  retention by default, `snapshot_enabled` master switch. The snapshot
  store itself is read-only to the agent.
- **Env scrubbing** — terminal/MCP child processes no longer inherit
  variables whose names contain KEY/SECRET/TOKEN; `.env` credentials
  can no longer be dumped with a single `env` command
  (`runtime.scrub_child_env`, default on).
- **Infrastructure files read-only** — config.toml / `.env` /
  mcp.toml / trusted_dirs.json / home sessions.db are rejected for
  agent writes (`[infra-guard]`), including the approved-execution
  path.
- **web_fetch egress gate** — unconditional SSRF validation (private /
  loopback / link-local / cloud-metadata ranges, post-DNS re-check);
  `allowed_domains` fail-closes non-interactive channels; interactive
  first visits to a new domain go through approval and persist to
  `web_domains.json`.
- **Terminal network-command audit marks** and unified
  "hard policy boundary" denial wording.
- **T2 deployment hardening** — a full restricted-account deployment
  guide (Windows dedicated account + service hardening, Linux systemd
  sandboxing) plus a zero-dependency privilege detection wired into
  `llaia doctor` and `/api/doctor` (elevated → warn).
- **Memory hygiene** — memory_write deduplicates normalized entries
  before persisting; MEMORY compaction becomes a three-stage pipeline
  (deterministic dedup → LLM semantic merge → output validation against
  source entries), with an automatic background trigger when MEMORY
  exceeds its budget. A tricked compressor can no longer inject
  untraceable content.

## Features

- **WebUI message queue** — while a turn is running, Send enqueues the
  message per instance; on turn end it auto-sends, restores the draft,
  or holds depending on the terminal event. Queue bar offers Send now
  and Steer actions.
- **Read-only built-in tools** (no approval):
  `file_list` (directory listing / wildcard recursive search, replaces
  terminal `ls`/`find`), `file_grep` (regex content search via the
  ripgrep library stack, replaces unreliable terminal grep on Windows),
  and `sqlite_query` (read-only SELECT on local .db files via bundled
  rusqlite — sessions.db inspection no longer needs T3-gated inline
  Python).
- **WebUI instance rail** — "+ New" button to create task instances,
  draggable width (140–420px, persisted), name filters for provider and
  model cards, GitHub-style contribution grid replacing token usage
  bars.
- **QQ approvals as separate button messages** — each approval renders
  its own interactive message instead of stacking.
- **Bare launch defaults to serve** — double-clicking the exe (or
  running without arguments) starts the server and opens the WebUI;
  startup errors pause the console instead of flashing away.
- **Cron inline-interpreter exemption** —
  `runtime.cron_allow_inline_interpreter` lets cron channels skip the
  T3 inline-interpreter gate (non-interactive channels cannot approve;
  the gate was pure friction there).

## Bug fixes

- **Approval cards on long-lived pages** — a stack of defects kept
  cards invisible or dead; fixed: process-nonce approval IDs (restarts
  no longer swallow new cards as duplicates), turn-end signal draining
  (done → auto-send → Busy race), cards broadcast to all WebSocket
  connections, busy state no longer permanently disables buttons,
  reconciliation heartbeat skips stale-marking while an instance lock
  is held, and a reload banner appears when the serve process was
  rebuilt.
- **Chinese full-text search** — unicode61 glued CJK runs into single
  tokens so Chinese MATCH almost always missed; a custom `fts_zh`
  function now splits CJK boundaries at index time and queries wrap CJK
  runs as quoted phrases. Existing indexes rebuild automatically.
- **Tool schemas** — `$ref`/`$defs` are inlined before sending to
  openai-compatible endpoints that cannot resolve JSON Pointer
  references.
- **Chat scrolling** — streaming and polling no longer yank the view to
  the bottom while reading scrollback (sticky only within 80px).
- **QQ reconnect** — exponential backoff (5s base, 60s cap) and
  transient network errors demoted to warn instead of spamming errors.
- Misc: `/provider` index list restricted to chat models, legacy
  tts/image_gen config migration no longer re-migrates written-back
  references, snapshot timestamp dirs are collision-proof, model card
  titles no longer split dotted ids.
