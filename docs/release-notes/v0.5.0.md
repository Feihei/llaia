# LLAIA v0.5.0

Originally planned as v0.4.1, but the batch grew into feature-level work with
behavior-incompatible changes, so per pre-1.0 semver it ships as a minor bump:
interpreter inline payloads now force human approval by default, task lines are
no longer implicitly resumed after restart, the auto session title feature is
gone, and the SOUL/USER placeholder templates were upgraded in place.

## Highlights

- **Session lines** ([ADR-0031](../adr/0031-task-session-model.md)) — the
  `/task` command family is renamed to `/session` (old names kept as pure
  forwarding aliases). Task lines are no longer implicitly resumed after
  restart (`latest_session()` only returns `kind='main'`); resume explicitly
  with `/session <name>`, which backfills the line's SQLite tail. `bound_path`
  became "the directory this line currently lives in", maintained automatically
  by `/move`, and switch/move notices share one `[scope]` status line.
- **The main line is now one forever** — `/new` was removed. "Turn the page" is
  `/archive [days]` (default 30): messages older than N days move into an
  archived bucket, the live context never notices, and `/clear` wipes the
  in-memory context (and the current todo list). The two are orthogonal by
  design — combine them yourself.
- **Chat session-line rail** — the WebUI chat view grew a left sidebar listing
  active lines: the main line pinned on top, open task lines below (cron and
  archived lines excluded). Clicking a line switches to it via the same
  backfill path as `/session` — plus one difference: the working directory
  follows the line's bound dir (the main line restores the home dir).
- **Thinking capability model** — thinking-capable models get real support:
  reasoning streams are stored and rendered as a collapsible block in chat;
  `[provider.<id>.model.<alias>.thinking]` declares per-model capability and
  `/reasoning` picks a level with hard gating (no silent downgrade); with
  `preserve = true` the assistant's prior thinking is echoed back on request.
  Guard retries no longer pretend to disable thinking on endpoints that can't.
- **Terminal script-bypass hardening** — inline interpreter payloads
  (`python -c`, `node -e`, heredocs, `curl … | bash`) now force approval even
  inside the workspace; path extraction from command lines was rewritten
  quote-aware with flag semantics (no more `git commit -m "a/b"` false
  positives); MSYS-style `/c/...` paths are converted before scope checks.
  Evaluated and rejected: recursive `sh -c` payload parsing, OS-level
  sandboxes (conflicts with the lightweight, single-crate positioning).

## Provider / model handling

- **Model-level `enabled` toggle** — keep parameters in `config.toml` but hide
  a model from `/provider` and the WebUI dropdowns; cross-references
  (fallback / compact / vision) are reconciled in memory only, so re-enabling
  restores everything. `LLAIA_HOME` env var and `llaia serve --host/--port`
  flags round out the CLI (bind overrides never leak into the file state).
- **Fenced tool calls** — ```` ```json ```` fences carrying `name` +
  `arguments` are now parsed as tool calls (strict validation; display-only
  JSON is never executed). This closes a real hole where small models wrapped
  `file_edit` calls in json fences and nothing happened. Trade-off, recorded
  honestly: generic json fences buffer until the closing fence instead of
  streaming verbatim.

## WebUI

- **Uploaded images actually reach the model** — a three-part path mismatch
  (`uploads/uploads/…` + Windows canonicalize prefix drift) made WebUI image
  uploads silently degrade to a text placeholder since the WS handler landed.
  Send/disconnect races got an outbox queue (`[queued] …` instead of a dead
  button), the todo/env status bar is always visible with honest error text,
  tool results are collapsible, your own images show in the chat stream, and
  the Sessions page gained a per-session **Archive older [N]d** hygiene tool
  plus a config-page fixed action header.

## Bug fixes / stability

- **Approval round-trip**: `/ok`-approved out-of-workspace operations were
  re-rejected by the execution layer's unconditional whitelist re-check — the
  approval gate had been decorative for that path since v0.4.0.
- **`file_edit` self-correction**: a not-found miss now returns an annotated
  file excerpt with line numbers, and line-ending-only mismatches (CRLF vs LF,
  the classic fresh-Windows-clone trap) get one tolerant retry instead of four
  burned turns.
- **Startup GC for `todos/`**: deleting a session or archiving a task line used
  to leak its todo JSON forever; orphans are swept at startup (archived-line
  lists are deliberately kept).
- Framework-facing messages are now English across channels (QQ token-expiry
  literals stay Chinese because they are matched verbatim).
