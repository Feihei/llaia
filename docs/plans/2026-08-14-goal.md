# P5: /goal 长期目标系统 实现计划

> ⚠️ **修订（2026-08-17）**：持久化方案已从「session metadata（sqlite）」改为「`<config_dir>/workspace/goal.md` 文件」（见 [ADR-0021](../adr/0021-goal-system.md) 修订节）。下方 **Task 2（session metadata 持久化）与 Task 7（压缩永留）已作废**——goal 不进 session、不进消息历史，无需这两步；其余 task（单活跃 goal、Runtime Context 注入、slash 命令、WebUI、超时核查）保持不变。路径 / 格式 / 命令集以 ADR-0021 修订节为准。

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:executing-plans 按任务顺序实现。步骤用 checkbox (`- [ ]`) 标记追踪。

**Goal:** 实现跨多轮持续推进的"长期目标"：用户用 `/goal <目标>` 设定，agent 在后续每轮都"记得"并在推进，可 `/goal-list` 查看、`/goal-cancel` 取消；目标持久化进 session、进度可视化。

**Architecture:** 单活跃 goal 存 `<config_dir>/workspace/goal.md`（默认 `~/.llaia/workspace/goal.md`，YAML frontmatter + 正文），随 agent 家目录落盘；激活时每轮注入 Runtime Context；slash 命令管理；WebUI 只读面板展示进度。参考 nanobot 的 sustained goals（其「超时豁免」对 llaia 不适用，已作废）。

**Tech Stack:** Rust + tokio + serde + rusqlite（现有 session 存储）

**参考设计:** [ADR-0021](../adr/0021-goal-system.md)

use llaia::goal::{GoalState, GoalStatus};
use serde_json::json;

#[test]
fn test_parse_active_goal() {
    let v = json!({"status":"active","objective":"读完整本《红楼梦》并做笔记","ui_summary":"第 20 回/120"});
    let g: GoalState = serde_json::from_value(v).unwrap();

fn test_serialize_roundtrip() {
    let g = GoalState::new("整理 2026 财报".into());
    let s = serde_json::to_string(&g).unwrap();
    let back: GoalState = serde_json::from_str(&s).unwrap();
    assert_eq!(back.objective, "整理 2026 财报");
    assert_eq!(back.status, GoalStatus::Active);
}

- [ ] **Step 2: 实现 GoalState**

```rust
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum GoalStatus { Active, Done, Cancelled }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct GoalState {
    pub status: GoalStatus,
    pub objective: String,
    #[serde(default)]
    pub ui_summary: Option<String>,
    pub created_at: i64,
    pub updated_at: i64,
}

impl GoalState {
    pub fn new(objective: String) -> Self {
        let now = chrono::Local::now().timestamp();
        Self { status: GoalStatus::Active, objective, ui_summary: None, created_at: now, updated_at: now }
    }
    pub fn is_active(&self) -> bool { self.status == GoalStatus::Active }
}
```

```rust
pub fn goal_state_runtime_lines(goal: &GoalState) -> Vec<String> {
    if !goal.is_active() { return vec![]; }
    let mut out = vec!["Goal (active):".to_string(), goal.objective.clone()];
    if let Some(s) = &goal.ui_summary {
        if !s.is_empty() { out.push(format!("Summary: {s}")); }
    }
    out
}
```
