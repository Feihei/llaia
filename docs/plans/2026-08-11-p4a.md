## 3. 关键设计点

- **前缀稳定性**：静态 system 前缀（SOUL/USER/MEMORY/Skills）整轮不变，只有尾部状态栏随当前时间变化，保证 provider KV cache 命中。`context.rs::test_system_prefix_stable_across_turns` 卡回归。
- **`None` 无回归**：`[runtime].timezone` 缺省跟随宿主机本地时区，与旧行为一致；非法值 warn 降级而非报错。
- **热更新**：serve 模式下 agent 的 `live_config` 与 WebChannel 共享同一 `Arc<RwLock<Config>>`，WebUI 改 `timezone` 写盘后下一轮对话即时生效（无需重启）。
- **共享清理**：Ctrl+C 与 `/api/shutdown` 走同一条 `shutdown_serve()` 收尾路径（cron 停止 + task abort）；容器内允许 stop（不同于 restart）。
